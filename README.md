# Aurotek Sales Portal

A Next.js-based sales portal integrating multiple communication and data processing channels.

## Features

- **LINE Bot Integration**: Customer communication through LINE Bot SDK
- **Email Processing**: IMAP integration for email handling
- **Database**: Supabase for data storage and management
- **Excel Processing**: XLSX parsing and generation capabilities
- **Testing**: Playwright automation testing

## Tech Stack

- **Frontend**: Next.js 14 with TypeScript
- **Styling**: Tailwind CSS
- **Backend**: Node.js with REST APIs
- **Database**: Supabase
- **Testing**: Playwright, ESLint
- **Quality**: Husky pre-commit hooks

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start

# Run linting
npm run lint
```

## Architecture

- Next.js app router structure
- API routes for backend functionality
- Integration with LINE Bot SDK for messaging
- IMAP client for email processing
- Supabase client for database operations
