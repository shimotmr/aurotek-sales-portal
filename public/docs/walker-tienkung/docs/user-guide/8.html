7. 遥控器说明

遥控器按键示意图​

遥控器开/关机​

  • 连按两次遥控器左下角的电源键，第二次按下后不要松手，可以打开/关闭遥控器。

  • 遥控器开机后，下方中央的指示灯亮起，从左至右分别表示遥控器的电量状态。当亮起第1、2、3、4个灯时，对应的电量分别为25%、50%、75%、100%。

遥控器按键说明​

拨杆定义​

拨杆功能位置档位含义
G整机运行与失能急停切换左：客户自定义业务模式（预留）
中：常规运行模式（默认）
右+C：关节失能
E功能模式选择上：客户自定义导航模式（预留）
中：标准动作控制模式（默认）
下：客户自定义业务模式（预留）
F按键功能切换上：语音播报
中：动作控制（默认）
下：半身控制模式（预留）
H运动模式切换左：行走模式
中：站立模式（默认）
右：跑步模式（仅强化学习）

按键功能速查及说明​

遥控器按键功能
A确认（短按）
语音开关/站立激活（长按）
B选择（按次数切换选项）
C僵停
D停止播放/回零
注意

长按定义为单键按下 1s 以上，连续短按定义为间隔小于 600ms 的多次短按。

标准动作模式​

注意

拨杆拨到如下位置进入标准动作模式：G 中 + E 中 + F 中

该模式为出厂默认遥控控制模式，支持站立、行走、跑步以及基础动作执行。

站立模式（H 中）​

  • D 键：回零（归初始位）
  • C 键：僵停
  • 长按 A 键：进入站立状态
  • H 从左拨回中（未长按 A）为默认行走准备状态，可通过摇杆移动

站立动作执行（H 中）​

  • 连续短按 B 键 N 次选择第 N 个动作（1~5：打招呼、握手、鞠躬、跳舞1、跳舞2）
  • 按 A 键确认执行
  • 左摇杆：上下为前倾/后仰，左右为左倾/右倾
  • 右摇杆：上下为站立升高/降低，左右为腰部顺/逆时针转动
  • C 键：中止当前动作（僵停）

行走模式（H 左）​

  • 左摇杆：前后/左右移动
  • 右摇杆：左右拨动控制旋转（顺/逆时针）
  • C 键：僵停

跑步模式（H 右）​

  • 左右摇杆控制逻辑与行走一致，运动速度更高
  • C 键：僵停

半身控制模式​

注意

拨杆拨到如下位置进入半身控制模式：G 中 + E 中 + F 下，目前仅支持天工行者无疆，且要求软件版本2.0.5.2以上。

该模式为半身控制模式：

  • 本模式不支持跑步
  • 除 C 键僵停外，其余控制不影响上肢状态
  • 上肢可在本模式下站立及行走时接受topic控制，如遥操作控制、录制动作播放等

该模式适用于仅下肢执行自动控制、上肢由用户远程接管的复合控制场景。

安全注意事项​

危险
  • 紧急停止：任何时候按下 C 键都可以立即僵停机器人。（需辅助保持平衡）
  • 失能急停：G 右 + C 键可以关节失能，用于高风险操作。
  • 拨杆组合：G 中 + E 中 + F 中为基础操作，其他组合请根据需要谨慎使用。
